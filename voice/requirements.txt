# IntelliVox voice agent — Python dependencies
#
# Prerequisites (install separately):
#   • Python 3.11+ (3.13 tested)
#   • ffmpeg
#       macOS:  brew install ffmpeg
#       Linux:  sudo pacman -S ffmpeg   /   sudo apt install ffmpeg
#   • Ollama          — https://ollama.com  +  ollama pull llama3.1
#   • Vision (computer_use): ollama pull llama3.2-vision
#
# Linux extras (recommended for desktop control on X11):
#   • xdg-utils, imagemagick (import), pactl/pulseaudio-utils, wmctrl
#       Manjaro/Arch: sudo pacman -S xdg-utils imagemagick libpulse wmctrl
#       Debian/Ubuntu: sudo apt install xdg-utils imagemagick pulseaudio-utils wmctrl
#   • Optional: xdotool (better frontmost-window detection), scrot
#   • pyttsx3 needs espeak-ng: sudo pacman -S espeak-ng  /  sudo apt install espeak-ng
#
# Setup:
#   cd voice
#   python3 -m venv .venv
#   source .venv/bin/activate      # Windows: .venv\Scripts\activate
#   pip install -r requirements.txt
#   python -m agent.orchestrator   # starts server on ws://127.0.0.1:8765/ws
#
# macOS permissions (System Settings → Privacy & Security):
#   • Microphone, Screen Recording, Accessibility, Automation
#
# Linux notes:
#   • Works best on X11. On Wayland, screenshots/automation may need grim + portal permissions.
#   • Grant your terminal/app access to input devices if the DE prompts for it.
